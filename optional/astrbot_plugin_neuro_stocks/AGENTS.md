# 可选历史股票游戏

目标：虚拟本金十万美元、仅现金整数股、每周三集中五日回放、中文实际依据、同级静态周记。版本 v0.1.0。使用主博客插件的人设配置、表情资源及模板，不依赖作者的私有 Neuro 插件。

只有管理员显式建立并恢复赛季才运行。保持历史截止、新闻 ID 验证、下一分钟撮合、费用/滑点、批次持久化与不重复付费保护。禁止加入真实下单、凭据硬编码或运行数据。历史行情必须预先导入并审核公司行动。离线测试与部署者实际数据权限验证须分开记录。

2026-11-10：公开模板提取完成，40 项离线测试通过（包含模拟 AstrBot 初始化、资源边界、预算隔离和五日回放）；未使用真实模型或真实数据凭据。发布前检查源码与示例，无运行数据和原部署身份/服务器信息。
